# 👨‍💼 Employee Management System

A console-based Employee Management System built using **Core Java**, **Object-Oriented Programming (OOP)**, and **Java Collections**.

---

## ✨ Features

* ➕ Add Employee
* 📋 View All Employees
* 🔍 Search Employee
* ✏️ Update Employee
* ❌ Delete Employee
* 🚪 Exit the application

---

## 🧠 Concepts Used

* Classes & Objects
* Constructors
* Encapsulation
* Inheritance
* Polymorphism
* Java Collections
* Object Interaction

---

## 🛠️ Technologies Used

* Java
* Core Java
* OOP Concepts
* Java Collections
* Eclipse IDE

---

## ▶️ How to Run

1. Clone or download the repository.
2. Open the project in Eclipse IDE.
3. Run the `EmployeeApp.java` file.
4. Follow the console menu to manage employees.
